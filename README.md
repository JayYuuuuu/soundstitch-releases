# SoundStitch 声拼 — 发布

macOS App：把 N 段短音频按随机间隔散布在一条长时间轴上（默认 1 小时），导出成一个音频文件。
外加分段裁切、顺序拼接、从视频分离音轨。

**这个仓库只存安装包**，源码不在这里。

## 下载

到 [Releases](../../releases/latest) 下载 `SoundStitch.zip`，解压后**把 `SoundStitch.app` 拖进「应用程序」文件夹**再打开。

拖进去这一步不能省：macOS 会把「从网上下载、又没被移动过」的 App 跑在一个只读的隔离位置上，
放在那儿它没法自我更新。

首次打开会被 Gatekeeper 拦一次（本 App 是 ad-hoc 签名，没有 Apple 开发者账号做不了公证）：
**系统设置 → 隐私与安全性 → 仍要打开**。之后不再提示。

## 更新

装好之后不用再来这里。App 每天自查一次，有新版就在后台下好，状态栏出现「重启启用」点一下即可。
